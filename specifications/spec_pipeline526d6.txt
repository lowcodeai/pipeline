Below is a sample code that implements the pipeline for detecting brain tumors in MRI scans using transfer learning with a pre-trained CNN model (e.g., EfficientNet). This code assumes you have the necessary libraries installed (e.g., TensorFlow, Keras, NumPy, etc.) and that your dataset is organized appropriately.

### Python Code for the Pipeline

```python
import os
import numpy as np
import tensorflow as tf
from tensorflow.keras.preprocessing.image import ImageDataGenerator
from tensorflow.keras.applications import EfficientNetB0
from tensorflow.keras.layers import Dense, GlobalAveragePooling2D
from tensorflow.keras.models import Model
from tensorflow.keras.optimizers import Adam
from sklearn.metrics import classification_report, confusion_matrix

# Set parameters
DATA_DIR = 'path/to/your/mri/dataset'  # Update this path
IMG_HEIGHT, IMG_WIDTH = 224, 224
BATCH_SIZE = 32
EPOCHS = 10  # Adjust based on your training time

# Step 1: Preprocess the MRI images
datagen = ImageDataGenerator(
    rescale=1.0/255.0,
    validation_split=0.2  # 20% for validation
)

train_generator = datagen.flow_from_directory(
    DATA_DIR,
    target_size=(IMG_HEIGHT, IMG_WIDTH),
    batch_size=BATCH_SIZE,
    class_mode='binary',
    subset='training'
)

validation_generator = datagen.flow_from_directory(
    DATA_DIR,
    target_size=(IMG_HEIGHT, IMG_WIDTH),
    batch_size=BATCH_SIZE,
    class_mode='binary',
    subset='validation'
)

# Step 2: Load a pre-trained model and replace the final classification layer
base_model = EfficientNetB0(weights='imagenet', include_top=False, input_shape=(IMG_HEIGHT, IMG_WIDTH, 3))
x = base_model.output
x = GlobalAveragePooling2D()(x)
x = Dense(1, activation='sigmoid')(x)  # Binary classification
model = Model(inputs=base_model.input, outputs=x)

# Step 3: Freeze the initial layers and train only the last few layers on your dataset
for layer in base_model.layers:
    layer.trainable = False

model.compile(optimizer=Adam(), loss='binary_crossentropy', metrics=['accuracy'])

# Train the model
model.fit(train_generator, validation_data=validation_generator, epochs=EPOCHS)

# Step 4: Evaluate the model using the test set
# Assuming you have a test set prepared similarly to the training set
test_generator = datagen.flow_from_directory(
    DATA_DIR,
    target_size=(IMG_HEIGHT, IMG_WIDTH),
    batch_size=BATCH_SIZE,
    class_mode='binary',
    subset='validation'  # Change this to your actual test set if available
)

# Evaluate the model
test_loss, test_accuracy = model.evaluate(test_generator)
print(f'Test Accuracy: {test_accuracy:.2f}')

# Generate classification report
predictions = model.predict(test_generator)
predicted_classes = np.where(predictions > 0.5, 1, 0)

# Assuming you have the true labels
true_classes = test_generator.classes
class_labels = list(test_generator.class_indices.keys())

print(classification_report(true_classes, predicted_classes, target_names=class_labels))
print(confusion_matrix(true_classes, predicted_classes))
```

### Notes:
1. **Data Directory:** Update the `DATA_DIR` variable to point to the location of your MRI dataset. The dataset should be organized in subdirectories for each class (e.g., `tumor` and `no_tumor`).
2. **Image Size:** The image size is set to 224x224, which is suitable for EfficientNet. Adjust if necessary based on the model you choose.
3. **Training Epochs:** The number of epochs is set to 10 for demonstration purposes. You may want to increase this based on your training time and performance.
4. **Evaluation:** The evaluation step assumes you have a test set. If not, you can use the validation set for evaluation.
