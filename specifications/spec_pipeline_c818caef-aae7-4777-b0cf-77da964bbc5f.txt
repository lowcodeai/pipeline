2. **Model Architecture:**
   - Build a CNN with several convolutional layers followed by max-pooling layers.

3. **Training:**
   - Use categorical cross-entropy as the loss function.
   - Train the model using a suitable optimizer (e.g., Adam) for a specified number of epochs.

4. **Evaluation:**
   - Evaluate the model using a confusion matrix, accuracy, precision, and recall.

#### Pipeline 2: Transfer Learning with Pre-trained Model (e.g., ResNet50)

**Steps:**
1. **Data Preprocessing:**
   - Resize images to the input size required by the pre-trained model (e.g., 224x224 pixels for ResNet50).
   - Normalize pixel values based on the pre-trained model's requirements (e.g., mean subtraction).

2. **Model Architecture:**
   - Load a pre-trained ResNet50 model without the top layer.
   - Add a global average pooling layer followed by a dense layer with softmax activation for classification.

3. **Training:**
   - Freeze the initial layers of the pre-trained model to retain learned features.
   - Train only the newly added layers with a lower learning rate.

4. **Evaluation:**
   - Evaluate the model using a confusion matrix, accuracy, precision, and recall.

**Pros:**
- Faster training time due to transfer learning.
- Leverages learned features from a large dataset, improving accuracy.

**Cons:**
- Limited flexibility in model architecture.
- May require fine-tuning for optimal performance.

#### Pipeline 3: Ensemble Learning with Multiple Models

**Steps:**
1. **Data Preprocessing:**
   - Resize images to a uniform size (e.g., 128x128 pixels).

3. **Ensemble Method:**

4. **Evaluation:**

**Pros:**

**Cons:**
